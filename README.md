# 🏥 Hospital Management Dashboard - Power BI

## 📌 Project Overview
This Power BI dashboard provides insights into hospital operations, patient management, revenue performance, and billing status. It helps monitor key healthcare metrics through interactive visualizations and reports.

## 🎯 Objectives
- Analyze Total Revenue and Patient Count
- Track Appointment Performance
- Monitor Doctor Performance
- Evaluate Insurance Provider Contributions
- Identify Pending Bills
- Analyze Department-wise Performance
- Monitor Monthly and Yearly Revenue Trends

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## 📊 Dashboard Features
- Interactive Slicers
- KPI Cards
- Ribbon Chart
- Funnel Chart
- Donut Chart
- Page Navigation Buttons

## 📈 Key Metrics
- Total Revenue
- Total Patients
- Total Appointments
- Pending Bills
- Doctor Performance
- Insurance Analysis
- Department-wise Insights

## 💡 Key Insights
- Identified top-performing doctors and departments.
- Analyzed patient and appointment trends.
- Tracked revenue growth over time.
- Monitored outstanding bills and payment status.
- Evaluated insurance provider contributions.
